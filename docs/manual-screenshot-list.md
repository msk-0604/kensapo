# KenSapo 取扱説明書用スクリーンショット一覧

撮影後の保存先（推奨）: `docs/manual-images/`

取扱説明書（`docs/KenSapo取扱説明書.md`）の差し込みパスと揃えています。

撮影のコツ

- 本番 URL: https://kensapo.vercel.app
- スマホ実機（または開発者ツールのモバイル表示）で撮る
- 個人情報・実在顧客名はぼかすか、デモ用データにする
- 赤い枠や矢印で「強調するボタン」を後から付けてもよい

---

- 画像番号: 00

- URL: （任意）`/dashboard` をぼかした全画面、またはロゴのみ
