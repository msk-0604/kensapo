## サービス概要

- サービス名: KenSapo（ケンサポ）
- 区分: 建設業向け現場スケジュール管理システム
- 本番URL: https://kensapo.vercel.app
- 対象: 建設会社の管理者・現場監督・作業員・事務担当者
- 対応端末: iPhone、Android、PCのモダンブラウザ
- UI方針: 60代でも使いやすい大文字・大きいボタン、日本語のみ
- 運営: 一人運営
- AI機能: 使わない（意図的に廃止済み）

## できること

会社単位で次を管理する。

1. 現場情報（名前、住所、担当者、期間、状態、メモ）
2. 作業員（名前、電話、職種、在籍）
3. 作業予定と開始・終了実績
4. 現場写真（撮影・保存・タイトル・コメント）
5. 日報（日付、天気、人数、作業内容、材料、問題点、翌日予定）
6. 工事進行チェックリスト（完了率表示）
7. Web Push通知（予定・開始終了・現場・日報・写真・進行の更新を、同じ会社の他ユーザーへ）

## 主な画面

- ログイン / 新規登録（会社＋管理者）
- ホーム（今日の概要）
- 予定（確認・登録・開始・終了）
- 現場一覧・詳細
- 写真 / 日報 / 工事進行
- 作業員
- 設定（通知・顔認証・アカウント）

下部メニューは「ホーム・予定・現場・設定」の4つ。

## 技術構成

- Next.js 16 / React / TypeScript / Tailwind
- Supabase（Auth / DB / Storage）
- Vercel ホスティング
- Web Push（Service Worker + VAPID）
- データは会社単位で RLS により分離
