KenSapo かんたん操作ガイド

A4一枚用・早見表　／　https://kensapo.vercel.app
画面下のメニュー：ホーム / 予定 / 現場 / 設定

ログインする

  1. KenSapoを開く
  2. 「メールアドレス」「パスワード」を入れる
  3. 「ログイン」をタップ

※ 初めての会社登録は「新規登録」→「アカウント作成」

現場を見る

  1. 下メニュー「現場」をタップ
  2. 一覧から現場を選ぶ
  3. 「この現場の詳細を見る →」をタップ

写真を追加する

  1. ホームで「写真を撮る」、または現場詳細で「写真を追加する」
  2. 現場を選ぶ
  3. 「写真を選ぶ・撮影する」→ 保存完了まで待つ

作業を開始する

  1. 「予定」または「ホーム」を開く
  2. 自分の予定を確認する
  3. 「作業を開始する」をタップ

作業を終了する

  1. 作業中の予定を開く
  2. 「作業を終了する」をタップ

日報を書く

  1. 「現場」→ 対象現場を開く
  2. 「日報を書く」をタップ
  3. 「今日の作業内容」などを入力
  4. 「日報を保存する」をタップ

予定を見る

  1. 下メニュー「予定」をタップ
  2. 日付の予定を確認する
  3. 必要なら「前の週／今日／次の週」で切り替える

通知を受け取る

  1. 「設定」を開く
  2. 「通知をオンにする」をタップ
  3. 端末で「許可」を選ぶ

※ iPhoneはホーム画面に追加したKenSapoから設定

困ったとき

  1. 電波のよい場所でもう一度試す
  2. アプリを閉じて開き直す
  3. 「設定」の一番下で「ログアウトする」→ 再ログイン
  4. 解決しないときは導入時の窓口へ連絡

管理者だけがよく使う操作

やりたいこと操作
現場を増やす現場 →「新しい現場を登録する」→「この現場を登録する」
作業員を増やす設定 →「作業員を管理する」→「作業員を登録する」
作業員を直す作業員一覧 →「この作業員を変更する」
予定を入れる予定 →「新しい予定を追加する」→「この予定を登録する」
工事進行を用意現場詳細 →「標準チェック項目を作成する」
注意　現場の削除機能はありません（状態を「完了」に変更）。AI報告書機能はありません。
