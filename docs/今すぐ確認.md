**全体の最終リスト:** `docs/最終詰めチェックリスト.md`

---

## A. 現場が保存できるか（1分）

1. ログインする
2. 「現場」→「新しい現場を登録する」
3. 現場の名前を入れて「この現場を登録する」
4. **詳細画面に飛べばOK**（「保存しています」のまま数分止まるのはNG）

止まっていたら Ctrl+Shift+R で再読み込みして再試行。

---

## B. 通知テスト（5分・スマホ2台推奨）

1. **受信側**スマホでログイン →「設定」→「通知をオンにする」→許可
2. iPhoneならホーム画面追加したKenSapoからオンにする
3. 受信側を**ロック**する
4. **操作側**（別アカウントまたはPC）で予定を追加、または「作業を開始する」
5. 受信側のロック画面にKenSapoの通知が届けばOK

自分の操作は自分には届きません。必ず別ユーザーで試してください。

- [ ] 現場 1件

- [ ] 写真 1枚
- [ ] 日報 1件
- [ ] 工事進行の「標準チェック項目を作成する」→1項目チェック

---

## D. 紙資料をPDFにする（2分）

1. エクスプローラーで `docs/print/` を開く（または `docs/print/index.html`）
2. 「かんたん操作ガイド」を開く
3. **Ctrl+P** → 「PDFに保存」
4. 同様に「問い合わせ先案内」「取扱説明書」もPDF化

取扱説明書HTMLの再生成（原稿を直したあと）:

```bash
node scripts/md-to-print-html.cjs
```
